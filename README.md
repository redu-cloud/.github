# redu.cloud

**redu.cloud** is a European cloud software platform focused on building secure, scalable, and modern cloud infrastructure.

The platform is designed around simplicity, transparency, and real-world usability, with an emphasis on private networking, compute, storage, and developer-friendly workflows.

## Why redu.cloud

Cloud infrastructure has become increasingly complex and opaque. redu.cloud is being built to explore new approaches to how cloud platforms are designed, operated, and experienced by developers and teams.

Key goals include:
- Clear and predictable infrastructure primitives
- Private networking as a first-class concept
- Scalable compute and storage without unnecessary complexity
- Tooling and documentation designed for engineers
- A focus on reliability, performance, and long-term maintainability

## Current status

The platform is currently in **beta** and actively evolving.  
This organization will host:
- Documentation
- Examples and reference implementations
- Tooling and supporting libraries
- Experimental projects related to the platform
